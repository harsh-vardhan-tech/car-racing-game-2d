# 🏎️ Car Racing Game 2D

A 2D top-down car racing game built with HTML5, CSS3, and JavaScript.

## Features

- **Player Control**: Use arrow keys to control your car
  - ⬆️ Accelerate
  - ⬇️ Brake
  - ⬅️➡️ Steer left/right
- **3 AI Cars**: Computer-controlled cars with basic lane-switching AI logic
- **Scrolling Road**: Animated road background with lane markings
- **Collision Detection**: Game ends when you collide with AI cars
- **Score Tracking**: Score increases as you progress
- **Modern UI**: Responsive CSS with gradients, shadows, and animations
- **800x600 Resolution**: Optimized canvas size for browser gameplay

## How to Play

1. Open `index.html` in a modern web browser
2. Click "Start Game" to begin
3. Use arrow keys to avoid other cars
4. Score increases the longer you survive
5. Game gets progressively harder

## Files

- `index.html` - Game structure and layout
- `styles.css` - Modern responsive styling
- `game.js` - Game logic and rendering
